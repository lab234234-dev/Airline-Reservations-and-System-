⚙️ 2. File-by-File Catalog ("કઈ ફાઇલ શું કામ કરે છે?")

Backend (Server Side - Port 5000)

ફાઇલનું નામ ટેકનોલોજી શું કામ કરે છે? (Functional Purpose)
server/server.js Express.js, Node.js મુખ્ય એન્ટ્રી પોઇન્ટ. MongoDB Atlas સાથે કનેક્ટ કરે છે, સિક્યોરિટી મિડલવેર (Helmet, CORS, Rate Limit) ચલાવે છે, REST APIs રન કરે છે અને બિલ્ટ Angular SPA ને પોર્ટ 5000 પર સર્વ કરે છે.
server/config/db.js Mongoose MongoDB Atlas ક્લાઉડ ક્લસ્ટર સાથે સેવ કરેલી કનેક્શન સ્ટ્રિંગથી કનેક્ટ કરે છે. જો નેટવર્ક કટ થાય તો આપમેળે 5 સેકન્ડમાં રિ-કનેક્ટ કરે છે.
server/controllers/authController.js bcryptjs, JWT યુઝર રજીસ્ટ્રેશન વખતે પાસવર્ડને bcrypt થી હેશ કરે છે. લોગિન વખતે પાસવર્ડ સરખાવીને 24-કલાકની એક્સપાયરી વાળો સુરક્ષિત JWT ટોકન બનાવે છે.
server/controllers/flightController.js Mongoose Queries બધી જ ફ્લાઇટ્સ શોધે છે, ડોમેસ્ટિક (રાજ્યો વચ્ચે) અને ઇન્ટરનેશનલ ફ્લાઇટ્સ ફિલ્ટર કરે છે, અને ચોક્કસ ફ્લાઇટનો સીટ મેટ્રિક્સ મોકલે છે.
server/controllers/bookingController.js Crypto, Mongoose યુનિક 6-અંકનો PNR (દા.ત. SK-8921) બનાવે છે. સીટનું સ્ટેટસ Booked કરે છે. PNR નાખીને વેબ ચેક-ઇન કરે છે અને checkInStatus: true કરે છે.
server/controllers/paymentController.js Razorpay SDK ક્રેડિટ કાર્ડ, યુપીઆઈ ક્યુઆર અને સ્કાયમાઇલ્સ પોઇન્ટ્સના પેમેન્ટ વેરિફિકેશન સંભાળે છે અને 10% લોયલ્ટી પોઇન્ટ્સ ક્રેડિટ કરે છે.
server/controllers/airportController.js Mongoose એરપોર્ટ ફિઝિકલ કાઉન્ટર ડેસ્ક પરથી વોક-ઇન પેસેન્જરો માટે સ્પોટ ટિકિટિંગ અને PNR ઇસ્યુ કરે છે.
server/controllers/adminController.js Aggregation Pipelines એડમિન પેનલ માટે ટોટલ રેવન્યુ, એક્ટિવ ફ્લાઇટ્સ, પેસેન્જર લોડ ફેક્ટર અને બુકિંગ્સના આંકડા ગણે છે.
server/middleware/authMiddleware.js jsonwebtoken દરેક પ્રોટેક્ટેડ રિક્વેસ્ટમાં JWT ટોકન સાચો છે કે નહીં તે ચેક કરે છે. એડમિન રાઉટ્સ પર યુઝરનો રોલ 'admin' છે કે નહીં તેની ખાતરી કરે છે.
server/middleware/rateLimiter.js express-rate-limit કોઈ હેકર વારંવાર ખોટો પાસવર્ડ નાખીને સર્વર હેંગ ન કરે તે માટે ૧ મિનિટમાં નિર્ધારિત રિક્વેસ્ટ્સ પછી આપમેળે બ્લોક કરે છે.
server/models/*.js Mongoose Schemas User (પ્રોફાઇલ/માઇલ્સ), Flight (રૂટ/સીટ્સ), Booking (PNR/ટિકિટ), CounterBooking (કાઉન્ટર રેકોર્ડ્સ) ના ડેટાબેઝ સ્કીમા ડિફાઇન કરે છે.
server/seed.js Database Seeder ડેટાબેઝમાં ડેમો માટે ૧૬ લાઇવ ડોમેસ્ટિક અને ઇન્ટરનેશનલ ફ્લાઇટ્સ અને એડમિન એકાઉન્ટ ઓટોમેટિક ઇન્સર્ટ કરે છે.

Frontend (Angular 18 Client - Port 4200 / Port 5000)

કમ્પોનન્ટ / ફાઇલ શું કામ કરે છે? (Functional Purpose)
components/navbar/navbar.component.ts ટોપ નેવિગેશન બાર. ફક્ત Logo, 'Search Flights' અને 'Profile' દર્શાવે છે (સ્વચ્છ અને મિનિમલ).

components/flights/flights.component.ts ફ્લાઇટ્સ સર્ચ પેજ. દર ૧ મિનિટે લાઇવ ફ્લાઇટ શેડ્યુલિંગ રિફ્રેશ કરે છે અને Leaflet.js Interactive Flight Route Map બતાવે છે.

components/checkin/checkin.component.ts ઓનલાઇન વેબ ચેક-ઇન. PNR નાખીને બુકિંગ ફેચ કરે છે, સીટ કન્ફર્મ કરે છે અને બોર્ડિંગ પાસ બનાવે છે.
components/boarding-pass/boarding-pass.component.ts ઓફિશિયલ બોર્ડિંગ પાસ. લાઇવ ફ્લાઇંગ ટ્રેકર પ્રોગ્રેસ બાર અને એરપોર્ટ સ્કેનર માટે Scannable QR Code બનાવે છે.
components/dashboard/dashboard.component.ts પ્રોફાઇલ પેજ. My Bookings, Web Check-in લિંક, Currency Exchange સિલેક્ટર અને Logout બટન ધરાવે છે.
components/counter-booking/counter-booking.component.ts એરપોર્ટ ફિઝિકલ કાઉન્ટર ડેસ્ક. એરપોર્ટ ગ્રાઉન્ડ સ્ટાફ માટે વોક-ઇન પેસેન્જરોને સીધી ટિકિટ કાઢી આપે છે.
components/admin/admin-dashboard.component.ts એડમિન પેનલ. રેવન્યુ ચાર્ટ્સ, પેસેન્જર લોડ ફેક્ટર, ફ્લાઇટ્સ મેનેજમેન્ટ (CRUD) અને પેસેન્જર મેનિફેસ્ટ ઓડિટિંગ.

services/currency.service.ts મલ્ટી-કરન્સી એન્જિન. INR, USD, EUR, GBP, AED, JPY વચ્ચે લાઇવ રન-ટાઇમ રેટ કન્વર્ઝન કરે છે.

🔄 3. End-to-End Architectural Workflows (પ્રોજેક્ટનો આખો વર્કફ્લો)

Workflow 1: ટિકિટ સર્ચ અને સીટ બુકિંગ પ્રક્રિયા

1
પેસેન્જર હોમ પેજ અથવા Search Flights પેજ પર Origin (Surat) અને Destination (Mumbai) પસંદ કરે છે.
2
Angular નું ApiService બેકએન્ડના GET /api/flights પર કોલ કરે છે. કંટ્રોલર MongoDB Atlas માંથી લિસ્ટ ફેચ કરીને મોકલે છે.
3
પેસેન્જર "🗺️ View Live Route Map" પર ક્લિક કરે છે -> Leaflet.js સુરત અને મુંબઈના કોઓર્ડિનેટ્સ વચ્ચે કર્વ લાઈન ડ્રો કરે છે.
4
પેસેન્જર "Select Seats & Book" કરે છે -> વિમાનની સીટોમાંથી સફેદ (⬜ Available) સીટ પસંદ કરે છે (તે 🟩 Green બને છે).
5
પેસેન્જર વિગત ભરીને પેમેન્ટ મોડલ ખોલે છે -> Card / UPI / SkyMiles પસંદ કરીને "Pay & Confirm" કરે છે.
6
બેકએન્ડ એટોમિક ટ્રાન્ઝેક્શનથી સીટ 'Booked' કરે છે, 6-અંકનો PNR (દા.ત. SK-8419) જનરેટ કરે છે અને ડેટાબેઝમાં બુકિંગ રેકોર્ડ સેવ થાય છે.

Workflow 2: ઓનલાઇન વેબ ચેક-ઇન & બોર્ડિંગ પાસ QR કોડ

1
પેસેન્જર Profile પેજ પરથી અથવા ડાયરેક્ટ Web Check-in પેજ પર જાય છે.
2
પેસેન્જર પોતાનો PNR નાખીને "Retrieve Booking" પર ક્લિક કરે છે. બેકએન્ડ બુકિંગ વિગત ચકાસે છે.
3
પેસેન્જર સીટ કન્ફર્મ કરીને "Generate Boarding Pass" દબાવે છે.
4
ડેટાબેઝમાં checkInStatus: true અપડેટ થાય છે.
5
ક્લાયન્ટ સાઇડ Canvas એન્જિન PNR અને પેસેન્જર ડેટા સાથેનો એન્ક્રિપ્ટેડ Scannable QR Code રેન્ડર કરે છે અને ફ્લાઇટનો લાઈવ ટ્રેકિંગ પ્રોગ્રેસ બાર દેખાય છે.

Workflow 3: એડમિન એનાલિટિક્સ અને એરપોર્ટ કાઉન્ટર ડેસ્ક

1
એડમિન admin@skyhigh.com / admin123 થી લોગિન કરે છે. JWT ટોકન ચકાસીને એડમિન પેનલ ઓપન થાય છે.
2
એડમિન ડેશબોર્ડ લાઈવ રેવન્યુ, સીટ લોડ ફેક્ટર, ફ્લાઇટ્સ એડ/ડિલીટ કરવાની સુવિધા આપે છે.

એરપોર્ટ ગ્રાઉન્ડ સ્ટાફ /counter-booking ઓપન કરીને વોક-ઇન પેસેન્જરો માટે સ્થળ પર જ કેશ/પીઓએસ ટિકિટ કાઢી આપે છે.

🚀 4. Production Deployment Guide (આ પ્રોજેક્ટને લાઇવ ક્લાઉડ પર કેવી રીતે ડિપ્લોય કરવો?)

આ પ્રોજેક્ટને આધુનિક Unified Cloud Architecture માં કન્ફિગર કરવામાં આવ્યો છે. તેનો અર્થ એ કે ફ્રન્ટએન્ડ અને બેકએન્ડ બંને **એક જ સર્વર પર એક જ પોર્ટ (Port 5000)** પર ચાલે છે:

૧-ક્લિક ડિપ્લોયમેન્ટ સ્ટેપ્સ (Render / Railway / Cloud VM):
  1. તમારા ગિટ રેપોઝીટરીને Render.com અથવા Railway.app સાથે કનેક્ટ કરો.
  2. Build Command: cd angular-client && npm install && npm run build && cd ../server && npm install
  3. Start Command: cd server && node server.js
  4. Environment Variables: 
    PORT=5000
MONGO_URI=mongodb+srv://AWD:AWD234234@cluster0.brveu1r.mongodb.net/airline-reservation?appName=Cluster0
JWT_SECRET=your_super_secure_jwt_secret_key_change_this_in_production_12345
NODE_ENV=production
  5. તમારો આખો પ્રોજેક્ટ ક્લાઉડ ડોમેન પર લાઇવ થઈ જશે (દા.ત. https://skyhigh-air.onrender.com)!
