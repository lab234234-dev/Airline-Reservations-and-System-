ABSTRACT

Civil aviation infrastructure demands rigorous standards for computerized reservation systems (CRS), passenger processing, and load manifest operations. Traditional academic and commercial flight booking implementations are often monolithic and suffer from rigid multi-page refreshes, cumbersome seat selection, and vulnerability to concurrency anomalies.

SkyHigh Air presents a decoupled, three-tier cloud-ready web architecture engineered for modern commercial air carriers. Built with React 18 and Vite 5.4 on the client-side, the platform delivers instantaneous sub-50ms reactive user experiences, visual 3-3 cabin layouts modeled directly after an Airbus A320neo, client-side canvas-compressed passenger biometric ID headshot uploading, and dynamic 24/7 web check-in producing scannable IATA-compliant dynamic QR boarding passes.

The backend is powered by a high-performance PHP 8.2 Object-Oriented RESTful Microservice API. It guarantees absolute immunity against SQL injection via PDO prepared statements, uses stateless JSON Web Token (JWT) authentication signed with HMAC-SHA256, and maintains an intelligent SQLite zero-config fallback for uninterrupted operation. The persistence layer operates on an ACID-compliant normalized MySQL database.

The system features dedicated interfaces for Passengers, Ground Staff (Airport Counter POS Desk), and Airline Executives (Admin Business Analytics & Timetable CRUD). Testing verified 100% pass rates across 20+ comprehensive functional and stress test cases.

CHAPTER 1: INTRODUCTION & PROBLEM FORMULATION

1.1 Background

Air transportation is the lifeblood of international travel and commerce. With airline passenger traffic expanding rapidly, carriers depend on software systems that can handle real-time inventory adjustments, seat reservations, and airport passenger check-ins with zero downtime.

1.2 Problem Statement

Legacy airline platforms present several key bottlenecks:

  • Monolithic Coupling: Server-side rendered views reload the entire page on every click, degrading passenger user experience.
  • Drop-Down Seat Selection: Seats are chosen from plain text menus without visual feedback of aircraft layout, window positions, or emergency exits.
  • Heavy Image Payloads: Uncompressed passenger photo uploads consume massive server disk storage and increase latency.
  • Absence of Walk-in Offline POS: Lack of dedicated interfaces for ground staff at airport check-in counters.

1.3 Project Objectives

  • Implement a Single-Page Application (SPA) using React 18 and Vite for instantaneous flight search and booking.
  • Construct an interactive visual 3-3 Airbus A320 cabin seat map.
  • Build an Object-Oriented REST API in PHP 8.2 with PDO and JWT security.
  • Provide passenger biometric photo upload with client-side HTML5 Canvas compression.
  • Generate electronic boarding passes with dynamic QR codes.
  • Provide an Airport Counter Desk for walk-in passengers and an Executive Admin Analytics Dashboard.

5.1 Conclusion

The SkyHigh Air project successfully validates that decoupling web application architecture into a modern React frontend and a lightweight PHP REST API provides substantial performance, security, and usability advantages over legacy monolithic reservation platforms.
