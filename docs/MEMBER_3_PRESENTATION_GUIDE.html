"Thank you, [Member 2 Name]. Respected Sir, my name is [Member 3 Name].

I was responsible for MongoDB Atlas Database Engineering, the Web Check-in & Boarding Pass Generation engine, the Airport Counter Desk, and Admin Analytics.

1. Database Architecture: We selected MongoDB Atlas as our cloud database engine. Because different aircraft types (like Boeing 787 vs Airbus A320) have completely distinct seat layouts and passenger manifests, MongoDB's flexible, non-relational document model allows us to store nested seat arrays and fast transactional records without complicated multi-table SQL JOINs.

2. Web Check-in & Dynamic Boarding Pass: Once a passenger has booked a ticket, they can perform Web Check-in via our portal by providing their PNR. Our system retrieves their reservation, updates the check-in status flag to 'true', and generates an official SkyHigh Air Boarding Pass. As you can see on screen, it features a real-time flight tracking indicator and a client-side rendered, scannable QR Code that encodes passenger credentials for gate security validation.

3. Airport Counter Ticketing Desk: To mirror real-world airport operations, we designed an Airport Counter Desk at /counter-booking. This allows airport desk agents to rapidly issue physical tickets to walk-in passengers with immediate PNR allocation.

4. Admin Fleet Analytics: Logging into /admin reveals our executive dashboard displaying real-time operational metrics: total system revenue, seat load factors, active domestic and international flights, and complete CRUD management over airline schedules.

I now hand back to our team lead, [Member 1 Name], to conclude our presentation. Thank you, Sir."

🧠 3. સર તને પૂછી શકે તેવા ટોપ ૫ ટેકનિકલ પ્રશ્નો (Viva Questions & Answers)

Q1: SQL (MySQL) કરતા MongoDB શા માટે એરલાઇન પ્રોજેક્ટ માટે વધુ સારું છે?
જવાબ: એરલાઇન ડેટાબેઝમાં દરેક પ્લેનની સીટિંગ રચના (Seat Matrix) અલગ હોય છે અને પેસેન્જર લિસ્ટ નેસ્ટેડ હોય છે. MySQL માં આ માટે ૪-૫ ટેબલ્સ બનાવીને JOINs કરવા પડે છે જે સ્લો થાય છે. MongoDB માં આખો સીટ મેટ્રિક્સ એક જ Document માં JSON એરે સ્વરૂપે ખૂબ ઝડપથી સેવ અને અપડેટ થઈ શકે છે.

Q2: Boarding Pass પરનો QR Code કેવી રીતે કામ કરે છે?
જવાબ: QR કોડ ક્લાયન્ટ સાઇડ Canvas લાઇબ્રેરી દ્વારા ડાયનેમિકલી જનરેટ થાય છે. તેમાં PNR, પેસેન્જરનું નામ, ફ્લાઇટ નંબર, સીટ નંબર અને સિક્યોરિટી ટોકન એન્કોડ હોય છે, જેને એરપોર્ટ ગેટ પર સ્કેનર દ્વારા સીધું વેરિફાય કરી શકાય છે.

Q3: Web Check-in થયા વગર પેસેન્જર પ્લેનમાં બેસી શકે?
જવાબ: ના. એરલાઇન નિયમો મુજબ બુકિંગ માત્ર સીટ રિઝર્વ કરે છે. જ્યાં સુધી પેસેન્જર વેબ ચેક-ઇન કરીને બોર્ડિંગ પાસ જનરેટ ન કરે ત્યાં સુધી ડેટાબેઝમાં checkInStatus: false રહે છે. ચેક-ઇન થતાં જ તે true બને છે અને સીટ કન્ફર્મ થાય છે.

Q4: એરપોર્ટ કાઉન્ટર ડેસ્ક શા માટે બનાવ્યો?
જવાબ: રિયલ-વર્લ્ડ એરપોર્ટ પર ઘણા પેસેન્જરો સીધા એરપોર્ટ પહોંચીને કાઉન્ટર પરથી સ્પોટ ટિકિટ લેતા હોય છે. આ મોડ્યુલ એરપોર્ટ ગ્રાઉન્ડ સ્ટાફને ઝડપથી ટિકિટ ઇસ્યુ કરવાની સુવિધા આપે છે.

Q5: એડમિન એનાલિટિક્સમાં કયા મેટ્રિક્સ બતાવો છો?
જવાબ: ટોટલ રેવન્યુ (રૂપિયામાં), ટોટલ બુકિંગ્સ, એક્ટિવ ફ્લાઇટ્સની સંખ્યા, ડોમેસ્ટિક vs ઇન્ટરનેશનલ ફ્લાઇટ્સનો રેશિયો અને સીટ ઓક્યુપન્સી (Load Factor).
