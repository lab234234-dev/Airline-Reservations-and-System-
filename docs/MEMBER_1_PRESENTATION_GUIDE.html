🚨 3. Emergency Troubleshooting Guide (પ્રેઝન્ટેશન વખતે કંઈ પ્રોબ્લેમ થાય તો શું કરવું?)

પ્રેઝન્ટેશન સમયે જો કોઈ ટેકનિકલ અડચણ આવે, તો ગભરાયા વગર આ સ્ટેપ્સ ફોલો કરવા:

કેસ ૧: બ્રાઉઝરમાં સાઇટ ન ખૂલે અથવા "Cannot GET" આવે:
• ટર્મિનલમાં ચેક કરો કે Angular સર્વર ચાલુ છે કે નહીં. જો બંધ હોય તો cd "C:\workspace\Airline Reservation system AWD\angular-client" માં જઈને npm start રન કરો.
કેસ ૨: ડેટા લોડ ન થાય અથવા ફ્લાઇટ્સ ન દેખાય:
• બેકએન્ડ સર્વર પોર્ટ 5000 પર ચાલુ છે કે નહીં તે ચેક કરો: બ્રાઉઝરમાં http://localhost:5000/api/health ઓપન કરો. જો {"status":"OK"} ન આવે તો સર્વર ટર્મિનલમાં cd "C:\workspace\Airline Reservation system AWD\server" માં જઈને node server.js રન કરો.
કેસ ૩: પેજ પર જૂની ડિઝાઇન કે કેશ ઇફેક્ટ દેખાય:

🧠 4. સર તને (Team Lead ને) પૂછી શકે તેવા અગત્યના વાઇવા પ્રશ્નો

Q1: Angular 18 Standalone Components નો મુખ્ય ફાયદો શું છે?
જવાબ: અગાઉના વર્ઝનમાં દરેક કમ્પોનન્ટ માટે NgModule બનાવવું પડતું હતું. Standalone કમ્પોનન્ટ્સમાં સીધા જ imports: [CommonModule, RouterOutlet] લખી શકાય છે. આનાથી બંડલ સાઇઝ ઘટી જાય છે, પેજ લોડિંગ ફાસ્ટ થાય છે અને કોડ વધારે ક્લીન બને છે.

Q2: RxJS અને Observables નો ઉપયોગ ક્યાં કર્યો છે?
જવાબ: બે જગ્યાએ: (૧) HttpClient માંથી બેકએન્ડ ડેટા ફેચ કરવા માટે Observables વપરાયા છે, અને (૨) રાઉટર ઇવેન્ટ્સ (NavigationEnd) ને સબસ્ક્રાઇબ કરીને પેજ બદલાય ત્યારે બેકગ્રાઉન્ડ ઇમેજ ઓટોમેટિક સ્વિચ કરવા માટે.

Q3: Leaflet.js મેપમાં ફ્લાઇટ રૂટ કેવી રીતે ડ્રો થાય છે?
જવાબ: દરેક શહેરના અક્ષાંશ-રેખાંશ (Latitude & Longitude) ડેટાબેઝમાં છે. Leaflet API ના L.polyline ફંક્શનથી બે પોઈન્ટ્સ વચ્ચે જિઓડેસિક કર્વ સાથે લાઈન બને છે અને તેના પર પ્લેનનું એનિમેશન ચાલે છે.

Q4: મલ્ટી-કરન્સી કન્વર્ઝન કેવી રીતે થાય છે?
જવાબ: currency.service.ts માં સેન્ટ્રલ એક્સચેન્જ રેટ્સ (INR, USD, EUR, GBP, AED, JPY) ડિફાઇન કર્યા છે. યુઝર નેવબારમાંથી જે કરન્સી પસંદ કરે તે મુજબ બધી ટિકિટના ભાવો રન-ટાઇમ પર કન્વર્ટ થઈને જે-તે કરન્સી સિમ્બોલ સાથે ડિસ્પ્લે થાય છે.
