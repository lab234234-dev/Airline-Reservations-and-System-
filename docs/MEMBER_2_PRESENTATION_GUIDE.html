"Thank you, [Member 1 Name]. Good morning respected Sir.

My name is [Member 2 Name], and I was responsible for the Backend Architecture, REST APIs, Security, and Payment Gateway integration of SkyHigh Air.

Our backend server runs on Node.js and Express.js on port 5000, communicating seamlessly with MongoDB Atlas. We structured the backend using a clean separation of concerns: Routes, Controllers, Middleware, and Models.

1. Security & Authentication: All passwords undergo salted cryptographic hashing using bcryptjs with 10 rounds before touching the database. For user sessions, we implemented stateless JSON Web Tokens (JWT) transmitted via secure HTTP headers. Upon final checkout, an atomic database validation verifies that the seat is still unreserved before transitioning it to 'Booked' and issuing a unique 6-character PNR.

3. Payment Engine: We integrated a comprehensive multi-mode payment gateway supporting simulated Credit/Debit cards with live 3D card preview, UPI QR code generation, Net Banking, and our proprietary SkyMiles Rewards, which awards passengers 10% loyalty miles on every transaction.

🧠 3. સર તને પૂછી શકે તેવા ટોપ ૫ ટેકનિકલ પ્રશ્નો (Viva Questions & Answers)

Q1: JWT (JSON Web Token) કેવી રીતે કામ કરે છે અને તે ક્યાં સ્ટોર થાય છે?
જવાબ: જ્યારે યુઝર લોગિન થાય, ત્યારે સર્વર તેના _id અને role ને સિક્રેટ કી (JWT_SECRET) સાથે સાઇન કરીને 24 કલાક માટે ટોકન બનાવે છે. આ ટોકન ક્લાયન્ટ પાસે સેવ થાય છે અને દરેક પ્રોટેક્ટેડ રિક્વેસ્ટ સાથે Authorization: Bearer <token> હેડરમાં મોકલવામાં આવે છે. સર્વર મિડલવેરમાં jwt.verify() થી તે ચેક કરે છે.

Q2: પાસવર્ડ સિક્યોરિટી માટે bcryptjs માં 10 Salt Rounds નો શું અર્થ થાય?
જવાબ: Salt એ એક રેન્ડમ ડેટા છે જે પાસવર્ડ સાથે મિક્સ થાય છે જેથી Rainbow Table એટેક ન થઈ શકે. 10 રાઉન્ડ્સ એટલે એલ્ગોરિધમ $2^{10} = 1024$ વાર કી સ્ટ્રેચિંગ કરે છે, જેથી પાસવર્ડ ક્રેક કરવો અશક્ય બની જાય છે.

Q3: RESTful API માં કયા HTTP Methods વાપર્યા છે?
જવાબ: • GET: ફ્લાઇટ્સ અને બુકિંગ્સ મેળવવા માટે.
• POST: નવી ટિકિટ બુક કરવા અને લોગિન કરવા માટે.
• PUT: વેબ ચેક-ઇન અને પ્રોફાઇલ અપડેટ કરવા માટે.
• DELETE: ફ્લાઇટ કેન્સલ કરવા માટે.

Q4: Express Rate Limiter કેમ મૂક્યો છે?
જવાબ: જો કોઈ હેકર વારંવાર ખોટો પાસવર્ડ નાખીને સર્વર હેંગ કરવા કે લોગિન ક્રેક કરવા પ્રયત્ન કરે, તો રેટ લિમિટર એક IP પરથી ૧ મિનિટમાં નિર્ધારિત રિક્વેસ્ટ્સ પછી તેને આપમેળે બ્લોક કરી દે છે (HTTP 429 Too Many Requests).

Q5: PNR નંબર કેવી રીતે જનરેટ થાય છે?
જવાબ: SK- પ્રીફિક્સ સાથે ૪ રેન્ડમ આલ્ફાન્યૂમેરિક અક્ષરો (દા.ત. SK-9812) જનરેટ થાય છે, અને ડેટાબેઝમાં ચેક કરવામાં આવે છે કે તે PNR પહેલાથી કોઈ બીજા પેસેન્જરનો નથી ને!
