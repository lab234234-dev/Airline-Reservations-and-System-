1. Executive Summary & Abstract

The SkyHigh Air Enterprise Reservation System is a full-stack, cloud-native commercial aviation platform built to simulate real-world passenger booking, check-in, and fleet intelligence operations adhering to IATA and DGCA industry workflows.

Existing college-level projects typically feature static flight schedules, single-tier seat booking without visual cabin mapping, and lack of role separation. SkyHigh Air solves these problems using modern web engineering on the MEAN Stack (MongoDB Atlas, Express.js, Angular 17/18 Standalone, Node.js).

3. Key Modules & Functional Workflows

  • Dynamic 1-Minute Live Flight Schedule: Real-time flight schedule generation and status countdowns.
  • Interactive 4-State Seat Concurrency Matrix: Precision seat picker categorizing seats into Available (⬜), Booked (🟥), Held/Reserved (🟨), and Extra-Legroom Premium (🟦).
  • Geospatial Route Visualization: Real-time vector map illustrating direct flight paths between Indian states and international hubs.
  • Integrated Airport Counter Desk: Expedited ticketing portal for airport ground staff to book walk-in tickets.
  • Online Web Check-in & Boarding Pass: Instant boarding pass generation featuring a live flight status progress bar and encrypted QR code.
  • SkyMiles Loyalty Program: 10% point accrual on every booking with direct redemption support in payment checkout.
  • Admin Fleet Intelligence Dashboard: Real-time financial revenue metrics, active flight count, and passenger load distribution.

5. Top 5 Viva Voce Questions & Answers

Q1: Why MongoDB over MySQL?
A: Aircraft seating configurations and passenger manifests vary dynamically across airframes. MongoDB's document model avoids complex relational multi-table JOINs and provides atomic array operations on seat matrices.

Q2: How is seat double-booking prevented?
A: Through multi-level concurrency validation. Seats selected are temporarily marked as 'held', and upon final payment confirmation, an atomic findAndModify transaction ensures the seat is still available before marking it as 'booked'.

Q3: How does JWT authentication work?
A: On successful login, the server signs a cryptographically secure token containing user ID and role with a 24-hour expiration. Protected endpoints inspect this token via Express middleware before granting access.

Q4: What is the benefit of Angular Standalone Components?
A: Eliminates NgModule boilerplate, enables direct component-level dependency injection, improves tree-shaking, and yields higher runtime performance.

Q5: How is the Boarding Pass QR Code generated?
A: Using client-side canvas rendering that encrypts a structured JSON payload containing PNR, passenger name, flight number, and seat for gate scanner verification.
